# Tool Box 🧰

وب‌اپ دو زبانه فارسی/انگلیسی با ابزارهای کاربردی، طراحی واکنش‌گرا و قابلیت PWA.

## اجرا
فایل `index.html` را باز کنید. برای PWA و Service Worker بهتر است پروژه را روی GitHub Pages منتشر کنید.

## انتشار در GitHub Pages
1. در GitHub یک Repository جدید با نام `tool-box` بسازید.
2. فایل‌های این پروژه را Upload کنید.
3. Commit changes بزنید.
4. در Settings → Pages، بخش Source را روی `Deploy from a branch` بگذارید.
5. Branch را `main` و Folder را `/root` انتخاب کنید و Save بزنید.
6. چند لحظه بعد لینک GitHub Pages نمایش داده می‌شود.

## تبدیل به APK
بعد از انتشار، لینک GitHub Pages را می‌توانید در سرویس‌های تبدیل Web App/PWA به APK استفاده کنید. برای یک APK حرفه‌ای‌تر، پروژه را می‌توان با Capacitor بسته‌بندی کرد.
